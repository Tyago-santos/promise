# Promise 💍

Web app de relacionamento voltado para **membros de A Igreja de Jesus Cristo dos Santos dos Últimos Dias**.  
O projeto tem como objetivo permitir que os integrantes possam **fazer amizades, namorar e conhecer novas pessoas**, respeitando valores e princípios da Igreja.

---

## 🧭 Visão Geral

O **Promise** é uma aplicação web moderna construída com foco em performance, organização de código e boa experiência do usuário.  
Ele utiliza tecnologias atuais do ecossistema React para criação de interfaces escaláveis e bem estruturadas.

---

## 🛠️ Tecnologias Utilizadas

- **React** — Biblioteca para construção de interfaces
- **Vite** — Ferramenta de build rápida e moderna
- **Tailwind CSS v4** — Estilização utilitária
- **@tanstack/react-router** — Roteamento tipado e performático
- **@tanstack/react-query** — Gerenciamento de estado assíncrono e cache de dados
- **React Hook Form** — Gerenciamento de formulários
- **Swiper** — Sliders e carrosséis interativos
- **PNPM** — Gerenciador de pacotes

---

## 📁 Estrutura do Projeto (exemplo)

```txt


# Clonar o repositório
git clone https://github.com/Tyago-santos/promise.git

# Entrar na pasta do projeto
cd promise

# Instalar dependências
pnpm add

# Iniciar o servidor de desenvolvimento
pnpm run dev



http://localhost:3000
```
